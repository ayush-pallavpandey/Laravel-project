# Laravel Task Manager API

## 🚀 Features
- Authentication (Laravel Sanctum)
- Role-based access
- Task & Project management
- REST API with validation

## 🛠 Tech Stack
- Laravel (PHP)
- MySQL
- Sanctum Auth

## ⚙️ Setup
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
